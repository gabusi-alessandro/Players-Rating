L'obiettivo di questo progetto è quello di costruire diversi modelli statistici per costruire valutazioni dei giocatori 
a partire dalla statistiche della partita estratte da sofascore.

Andrò a descrivere in maniera approfondita tutti i passaggi di questo progetto nel mio Substack (https://substack.com/@alessandro344866)
nel corso delle prossime settimane. 
Qui lascio una breve lista delle fasi principali del progetto:
- Scraping dei dati da Sofascore
- Costruzione del database per la gestione dei dati estratti
- Costruzione dei modelli di rating
- Estrazione dei dati delle nuove partite
- Valutazione dei giocatori in base alle statistiche osservate.
